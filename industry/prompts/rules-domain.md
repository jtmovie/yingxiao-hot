【营销领域写作与翻译规则 — 本平台内容是营销、广告、电商和内容运营行业，严格遵守】

1. 歧义默认值：以下词按营销行业含义理解和翻译：
   - Campaign = 营销活动（不译"竞选"/"战役"）
   - Creative = 广告创意 / 素材
   - Placement = 广告位
   - Impression = 曝光（不译"印象"）
   - Conversion = 转化
   - Engagement = 互动
   - Reach = 触达
   - Influencer / Creator = 达人 / 创作者（不译"影响者"）
   - Brand ambassador = 品牌代言人
   - Collab / Collaboration（品牌之间）= 联名
   - Retail media = 零售媒体
   - Programmatic = 程序化广告
   - Agency = 广告公司 / 代理商（不译"机构"/"中介"）
   - Pitch（代理商之间）= 比稿
   - Account（代理商语境）= 客户 / 业务（不译"账户"）

2. 以下写法**一律保留原样**，不翻译不展开：
   - 行业缩写：KOL / KOC / ROI / ROAS / GMV / CPM / CPC / CPA / CTR / CVR / UV / PV / DAU / MAU / SEO / SEM / GEO / DTC / DSP / SaaS / AIGC / IP
   - 大促和节点：618 / 双11 / 双12 / 年货节 / 38 节
   - 平台的产品和工具名照原样写：聚光、蒲公英、乘风（小红书）；巨量引擎、巨量千川、巨量云图、星图（抖音）；腾讯广告、视频号小店、企业微信（腾讯）；阿里妈妈、万相台（淘天）；京准通（京东）；磁力引擎、磁力金牛（快手）；花火（B站）
   - 海外公司和代理商：WPP / Omnicom / Publicis / Dentsu / Havas / IPG 等保留英文原名

3. 平台名用国内通行的中文名：小红书、抖音、微信、视频号、淘宝、天猫、京东、拼多多、美团、快手、B站（哔哩哔哩）、微博、知乎。海外平台首次出现可双标，如"Meta（Facebook 母公司）"，后续保持一致。

4. 不要把一个平台的规则、产品或数据写到另一个平台头上；材料没说是哪个平台时，不猜。

5. 数字、日期、金额、比例 **一字不改**保留：
   - 生效日期、处罚天数、扣分数、佣金比例、GMV、增长率照原文
   - 金额、比例、区间必须保留原文的阿拉伯数字和单位；不要把“10%-20%”改写成“一到两成”
   - URL 原样
